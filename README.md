# Basic Port Scanner (Python)

## Project Overview
This project is a simple port scanner built using Python. It is designed to scan a range of ports on a target machine and identify which ports are open.

The goal of this project is to understand how network communication works and how devices expose services through ports.

## How It Works
The program tries to connect to a range of TCP ports on a target IP address or domain name. If the connection is successful, the port is considered open. If not, it is considered closed.

## Features
- Scans a user-defined range of ports
- Converts domain names to IP addresses
- Identifies open ports using TCP connection attempts
- Displays scan results in real time

## Technologies Used
- Python
- Socket programming
- TCP/IP networking concepts
